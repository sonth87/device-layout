# Declaring & Adding Custom Apps

In `@sonth87/device-layout`, any feature, dashboard panel, or external utility can be packaged as an isolated **App** running inside its own window container.

---

## Step 1: Create the App React Component

Every app component receives `{ appId, windowId }` via `AppContentProps`:

```tsx
// src/apps/SalesAnalyticsApp.tsx
import React, { useState } from 'react';
import type { AppContentProps } from '@sonth87/device-layout';

export function SalesAnalyticsApp({ appId, windowId }: AppContentProps) {
  const [activeTab, setActiveTab] = useState<'overview' | 'reports'>('overview');

  return (
    <div className="flex flex-col h-full bg-slate-950 text-slate-100 font-sans">
      {/* Header Bar */}
      <div className="flex items-center justify-between px-4 py-2 bg-slate-900 border-b border-slate-800">
        <h3 className="text-sm font-semibold text-slate-200">Sales Dashboard</h3>
        <div className="flex gap-2 text-xs">
          <button
            onClick={() => setActiveTab('overview')}
            className={`px-2.5 py-1 rounded ${activeTab === 'overview' ? 'bg-blue-600 text-white' : 'text-slate-400 hover:text-white'}`}
          >
            Overview
          </button>
          <button
            onClick={() => setActiveTab('reports')}
            className={`px-2.5 py-1 rounded ${activeTab === 'reports' ? 'bg-blue-600 text-white' : 'text-slate-400 hover:text-white'}`}
          >
            Reports
          </button>
        </div>
      </div>

      {/* Main Body */}
      <div className="flex-1 p-4 overflow-auto">
        {activeTab === 'overview' ? (
          <div>
            <p className="text-slate-400 text-sm mb-4">Running instance: <code className="text-emerald-400">{windowId}</code></p>
            <div className="grid grid-cols-2 gap-3">
              <div className="p-3 bg-slate-900 border border-slate-800 rounded-lg">
                <span className="text-xs text-slate-400">Total Revenue</span>
                <p className="text-xl font-bold text-emerald-400 mt-1">$48,250</p>
              </div>
              <div className="p-3 bg-slate-900 border border-slate-800 rounded-lg">
                <span className="text-xs text-slate-400">Active Subscriptions</span>
                <p className="text-xl font-bold text-blue-400 mt-1">1,240</p>
              </div>
            </div>
          </div>
        ) : (
          <div className="text-sm text-slate-300">Detailed sales reports list...</div>
        )}
      </div>
    </div>
  );
}
```

## Step 2: Declare `AppConfig`

Define the application metadata and pass the component to the `render` property:

```tsx
// src/config/apps.ts
import type { AppConfig } from '@sonth87/device-layout';
import { SalesAnalyticsApp } from '@/apps/SalesAnalyticsApp';

export const customApps: AppConfig[] = [
  {
    id: 'sales-analytics',
    name: 'Sales Analytics',
    icon: 'lucide:TrendingUp',
    iconColor: ['#10B981', '#047857'], // Green gradient
    render: SalesAnalyticsApp,
    defaultSize: { width: 750, height: 500 },
    minSize: { width: 400, height: 300 },
    launchMode: 'single', // 'single' prevents duplicate window instances
    hasMenuBar: true,
    menuBarMenus: [
      {
        label: 'File',
        items: [
          { key: 'export-csv', label: 'Export Data (CSV)', shortcut: '⌘E', action: 'exportCsv' },
        ],
      },
    ],
  },
];
```

---

## Step 3: Register in `<DeviceLayout />`

Pass `customApps` array into the root `<DeviceLayout />`:

```tsx
<DeviceLayout
  colorScheme="dark"
  osTheme="macos"
  apps={customApps}
/>
```

---

## 💡 Best Practices for App Components

1. **Use `h-full overflow-auto`**: Ensure your app root element uses `h-full` so it expands to fit the window container height, and `overflow-auto` for inner scrolling.
2. **Launch Modes**:
   - `launchMode: 'single'`: If the app is already open, clicking its Dock icon brings the existing window to focus.
   - `launchMode: 'multi'`: Every click opens a new isolated window instance.
3. **State Scoping**: Store transient UI state (selected tabs, input text) inside local React state (`useState`), and global shared state using Zustand or React Context.
