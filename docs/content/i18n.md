# Internationalization (i18n)

## Overview

Device Layout includes a lightweight, type-safe per-app i18n system. Each app can ship its own locale dictionary as part of `AppConfig`. The system language is selected globally in System Settings → General → Language, and the active language is stored in `desktopSlice.language`.

---

## Supported Languages

| Code | Language |
|------|----------|
| `en` | English (US) — required, used as fallback |
| `vi` | Tiếng Việt |
| `ja` | 日本語 |
| `ko` | 한국어 |
| `zh` | 简体中文 |
| `th` | ไทย |

---

## Declaring App Locales

Add a `locale` field to your `AppConfig`:

```ts
// src/config/apps.config.ts
{
  id: 'my-app',
  name: 'My App',
  locale: {
    en: {
      title: 'My App',
      search: 'Search...',
      newItem: 'New Item',
    },
    vi: {
      title: 'Ứng dụng của tôi',
      search: 'Tìm kiếm...',
      newItem: 'Mục mới',
    },
    ja: {
      title: 'マイアプリ',
      search: '検索...',
      newItem: '新しいアイテム',
    },
  },
}
```

> **`en` is required.** It is the fallback for any language the app doesn't support.

## Reading Locale Strings in a Component

Use the `language` value from the store and access the locale through the `AppConfig`:

```tsx
'use client';

import { useStore } from '@/store';

export function MyApp({ appId }: { appId: string; windowId: string }) {
  const appConfig = useStore((s) => s.apps[appId]);
  const language = useStore((s) => s.language);

  // Pick the locale for the current language, falling back to 'en'
  const locale = appConfig?.locale?.[language] ?? appConfig?.locale?.['en'] ?? {};
  const t = (key: string) => locale[key] ?? key;

  return (
    <div>
      <h1>{t('title')}</h1>
      <input placeholder={t('search')} />
    </div>
  );
}
```

## Type Safety

The `AppLocale` type ensures `en` is always present:

```ts
export interface AppLocale<T extends Record<string, string> = Record<string, string>> {
  en: T;
  vi?: Record<string, string>;
  ja?: Record<string, string>;
  ko?: Record<string, string>;
  zh?: Record<string, string>;
  th?: Record<string, string>;
}
```

Use `satisfies AppLocale` to get type checking on your locale object:

```ts
const MY_LOCALE = {
  en: { title: 'My App', save: 'Save' },
  vi: { title: 'Ứng dụng', save: 'Lưu' },
} satisfies AppLocale;
```

## Changing Language

The user selects a language in **System Settings → General → Language**. The selection is persisted in `localStorage`. Apps re-render automatically via Zustand subscription when the language changes.

To programmatically change language:

```ts
const setLanguage = useStore((s) => s.setLanguage);
setLanguage('vi');
```
